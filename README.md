## 带宽和流量才是藏在配置表后面的限制

买 VPS 最容易踩的坑不是 CPU 核数不够，是带宽给得太小。

同样是 1 核 1G，LightLayer 的几条产品线带宽差得很远：月付 Global 给 100Mbps 不限流量，Pay As You Go 给 200Mbps 不限流量，伦敦那条给 300Mbps 配 1TB 月流量。而年付特价档的带宽普遍收窄，用之前必须在套餐页确认具体数值——5Mbps 和 100Mbps 是两种完全不同的使用体验，前者只能跑轻量代理和纯文本站点，后者才谈得上建站和传输文件。

同类问题在其他商家身上也常见。DMIT 的 Premium 和 Eyeball 系列流量用完直接暂停服务，只有 Tier 1 超量后限速 50–100Mbps 继续跑；RackNerd 全系 1Gbps 但限量套餐售完即止。这些条款都写在 FAQ 里，不在价格表上。

下单前的动作很简单：把套餐页往下拉，找到带宽和流量那一行，看清楚是"不限流量"还是"每月 X TB"，是"100Mbps 独享"还是"峰值 100Mbps"。

## 买之前先用测试 IP 跑一遍

LightLayer 对每个机房都公布了测试 IP，有测评整理出洛杉矶 Premium 段是 128.241.250.254，香港 Premium 段是 156.245.234.254。这个信息比任何评测文章都实用—— ping 和 traceroute 五分钟，能看出你家宽带到这个机房走的是哪条路、延迟什么量级、丢不丢包。

具体做法：

1. 在自己常用的网络环境（家里宽带、公司网络、手机热点各测一次）ping 测试 IP，记录平均延迟
2. 用 traceroute 看回程经过哪些节点，绕不绕美国西海岸以外的地方
3. 晚上八九点再测一遍，和下午的数据对比，差距大说明超售严重

作为参照量级：有测评显示 RackNerd 洛杉矶 DC02 的国内平均延迟约 197ms，上海电信能到 135ms 左右；香港节点普遍在 20–50ms。洛杉矶机房落在 150–200ms 属于正常，超过 250ms 就要看路由是不是绕了。

如果测试 IP 已经失效或者官网提供了新的地址，以官网当前公布的为准。
